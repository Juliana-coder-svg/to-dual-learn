# To Dual Learn — MVP

Платформа микрообучения. Преподаватель загружает материалы, AI собирает из них уроки, задания и конспекты, отвечает в чате по материалам и проверяет домашки. Студент проходит по уроку в день, отвечает на задачу, получает фидбек AI-ментора, копит streak и XP, повторяет флешкарты через 1, 2, 7, 14 и 30 дней.

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать ключи Supabase и ключ модели
npm run dev                   # http://localhost:3000
```

Модель подключается одним из двух способов: `ANTHROPIC_API_KEY` (Anthropic напрямую, с кэшированием промпта и server-side fallback) или `OPENAI_COMPAT_API_KEY` + `OPENAI_COMPAT_BASE_URL` + `OPENAI_COMPAT_MODEL` (любой OpenAI-совместимый эндпоинт: OpenRouter, GigaChat, Qwen во внутреннем контуре). Без ключей приложение работает в демо-режиме: все AI-ответы — заглушки, интерфейс прокликивается целиком. Каждый вызов модели пишется в таблицу `ai_calls` с токенами и оценкой стоимости; расход виден в шапке курса и на вкладке «Настройки». Стоимость оценочная: считается по семейству модели, которая ответила (через fallback запрос может уйти на другую), точная сумма в кабинете поставщика. Общая инструкция и материалы курса идут в начале системного промпта с точками кэша, текст задачи после них, поэтому повторные запросы по курсу читают материалы из кэша.

База и вход — Supabase. Схема в `supabase/migrations/0001_init.sql`; доступ к строкам ограничивает Row Level Security: преподаватель видит свои курсы и всё внутри, студент — курсы, где записан, опубликованные уроки, свои ответы и карточки. Вход в двух режимах (`AUTH_LOGIN_MODE`): `direct`, по умолчанию, — почта, имя и роль, вход сразу без письма (для демо и закрытых пилотов: любой, кто знает почту, войдёт под ней); `magic` — Supabase присылает ссылку на почту, `/auth/callback` открывает сессию. В обоих режимах имя и роль из формы попадают в `profiles`. Роль переключается кнопкой в шапке. Крон писем работает от service-role ключа, потому что у него нет пользователя.

Supabase поднимается за пять минут:

1. Создать проект на supabase.com и вписать в `.env.local` Project URL, publishable-ключ (`NEXT_PUBLIC_SUPABASE_ANON_KEY`) и secret-ключ (`SUPABASE_SERVICE_ROLE_KEY`, только на сервере).
2. Выполнить файлы из `supabase/migrations/` по порядку номеров в SQL Editor проекта (или `supabase db push`, если стоит CLI). `0001` создаёт таблицы, триггер профиля, RPC и политики RLS; следующие добавляют согласия, отметку проверки урока и ограничения на правку профиля.
3. В Authentication → URL Configuration добавить в Redirect URLs адрес приложения с `/**`, например `http://localhost:3000/**` и адрес на Vercel, иначе ссылка из письма не вернёт на сайт. Для прода задать `NEXT_PUBLIC_SITE_URL`.
4. Встроенная почта Supabase отправляет несколько писем в час и не шлёт на зарезервированные домены вроде example.com. Для реальных пользователей нужен свой SMTP в Authentication → Email.

## Сценарии

**Преподаватель** (`/teach`): создать курс или добавить готовый демо-курс → загрузить PDF/TXT/MD или вставить текст → «Собрать уроки» (с проходом методиста-ревьюера) → поправить в редакторе, переставить, опубликовать → дать студентам код или ссылку `/join/КОД`. Вкладки: Материалы, Уроки, Генерация (задание, тест, конспект, план занятия, структура презентации), Чат по материалам, Проверка ДЗ (вставка текста или CSV из LMS, выгрузка результатов в CSV), Студенты, Настройки (образовательные результаты, тон, лимит уроков в день, образцы оценок для калибровки, расход по операциям).

**Студент** (`/learn`): ввести код курса → урок дня (интро → задача → фидбек по критериям) → возражение на оценку, если не согласен → повторение (`/learn/review`, 2–3 карточки на урок) → история ответов (`/learn/history`). По умолчанию один новый урок в день. Письмо «урок дня» уходит кроном (`/api/cron/daily`, Resend), если задан `RESEND_API_KEY`.

## Структура

- `src/app/` — страницы (App Router) и route handlers в `src/app/api/`
- `src/lib/ai/index.ts` — единственная точка вызова модели с учётом расхода; `providers/` — Anthropic и OpenAI-совместимый; `demo.ts` — заглушки
- `src/lib/prompts/` — промпты, один файл на промпт (править можно без кода)
- `src/lib/db/queries.ts` — все запросы к базе через supabase-js (RLS проверяет доступ); `src/lib/supabase/` — клиенты, типы схемы, сервисный режим для крона; `src/proxy.ts` — обновление сессии
- `supabase/migrations/` — SQL-миграции (таблицы, триггер профиля, RPC, политики RLS)
- `src/lib/lessons/types.ts` — zod-схемы урока, фидбека, результатов проверки
- `src/lib/progress/` — streak, XP, интервалы повторения
- `src/lib/auth/` — обёртка над Supabase Auth, cookie с данными формы входа, проверки доступа как второй слой поверх RLS
- `content/courses/` — готовые курсы для кнопки «Добавить демо-курс»
- `docs/` — разбор продукта с шести позиций и страница технологии для Сколково
- `src/components/` — UI (shadcn/ui в `ui/`, остальное по ролям)

## Стоимость

Замер 7 октября 2026 на `anthropic/claude-opus-5.5` через OpenRouter (родной эндпоинт Anthropic, вариант 1а в `.env.example`). Курс: PDF вебинара на 52 страницы и текст программы, вместе около 10,7 тыс. токенов материалов. Цены Opus 5.5: $4 за миллион входных токенов, $20 выходных, запись в кэш $5, чтение из кэша $0.20. Стоимость оценочная, точная сумма в кабинете поставщика.

| Сценарий | Вход | Кэш: запись / чтение | Выход | Время | Стоимость |
|---|---|---|---|---|---|
| Извлечение PDF, 52 стр. (ответил Opus 4.8 после fallback) | 91 893 | 0 / 0 | 9 941 | 170 с | $0.71 |
| Сборка 5 уроков | 22 | 13 886 / 0 | 11 778 | 146 с | $0.31 |
| Проход ревьюера по 5 урокам | 24 | 21 598 / 0 | 13 981 | 164 с | $0.39 |
| Документ: задание | 16 | 10 930 / 0 | 3 402 | 112 с | $0.12 |
| Документ: тест | 16 | 10 963 / 0 | 8 067 | 79 с | $0.22 |
| Документ: конспект | 198 | 10 725 / 0 | 7 282 | 125 с | $0.20 |
| Документ: план занятия (из кэша) | 240 | 0 / 10 725 | 11 304 | 130 с | $0.23 |
| Документ: структура презентации (из кэша) | 219 | 0 / 10 725 | 6 750 | 167 с | $0.14 |
| Оценка ответа студента, 3 ответа | 950–1 205 | 1 581 / 1 581 | 788–1 296 | 25–162 с | $0.02–0.04 |
| Проверка 5 домашних работ | 1 227 | 12 026 / 0 | 3 990 | 171 с | $0.15 |
| Вопрос в чате, 2 вопроса (из кэша) | 219–1 157 | 0 / 10 725 | 1 456–2 054 | 24–127 с | $0.03–0.05 |
| Ещё 3 урока к существующим | 688 | 13 839 / 0 | 7 435 | 93 с | $0.22 |

Весь прогон: 15 вызовов, $2.84. Ориентир на курс: загрузка материалов и сборка уроков с ревьюером около $1.40, каждый документ $0.12–0.23, проверка пачки домашних работ $0.15, ответ студенту $0.02–0.04.

Что показал замер:

- **Кэш читается**, когда префикс совпадает: общая инструкция и материалы кэшируются один раз на курс, задача идёт после точки кэша. Вызовы со structured output (уроки, оценка, проверка работ) получают свой префикс на каждую JSON-схему, поэтому документ и чат читают один кэш, а сборка уроков и проверка работ пишут свои. Повторный вызов с той же схемой в течение пяти минут читает из кэша. Минимальный размер префикса для кэша у Opus 5.5 — 4096 токенов: у курса с одним коротким текстом кэша не будет.
- **Fallback через OpenRouter срабатывает и на сбой провайдера**, не только на отказ модели: первое извлечение PDF ушло на Opus 4.8, повтор того же файла прошёл на Opus 5.5 за 115 с. Модель, которая ответила, пишется в `ai_calls`.
- **Извлечение PDF полное**: 52 страницы дали 23,7 тыс. знаков Markdown до последнего слайда, `stop_reason: end_turn` при лимите 64 тыс. токенов.
- **Время ответа** на генерации 1,5–3 минуты, маршруты рассчитаны на 300 с. Оценка ответа студента от 25 с до 2,5 мин в зависимости от того, насколько ответ спорный.
