# To Dual Learn — MVP

Платформа микрообучения. Преподаватель загружает материалы, AI собирает из них уроки, задания и конспекты, отвечает в чате по материалам и проверяет домашки. Студент проходит по уроку в день, отвечает на задачу, получает фидбек AI-ментора, копит streak и XP, повторяет флешкарты через 1, 2, 7, 14 и 30 дней.

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать ANTHROPIC_API_KEY
npm run dev                   # http://localhost:3000
```

Модель подключается одним из двух способов: `ANTHROPIC_API_KEY` (Anthropic напрямую, с кэшированием промпта и server-side fallback) или `OPENAI_COMPAT_API_KEY` + `OPENAI_COMPAT_BASE_URL` + `OPENAI_COMPAT_MODEL` (любой OpenAI-совместимый эндпоинт: OpenRouter, GigaChat, Qwen во внутреннем контуре). Без ключей приложение работает в демо-режиме: все AI-ответы — заглушки, интерфейс прокликивается целиком. Каждый вызов модели пишется в таблицу `ai_calls` с токенами и оценкой стоимости; расход виден в шапке курса и на вкладке «Настройки». Стоимость оценочная: считается по семейству модели, которая ответила (через fallback запрос может уйти на другую), точная сумма в кабинете поставщика. Общая инструкция и материалы курса идут в начале системного промпта с точками кэша, текст задачи после них, поэтому повторные запросы по курсу читают материалы из кэша.

База — SQLite через встроенный `node:sqlite` (Node 22.5+), файл `data/app.db` создаётся сам. Вход — по почте и имени без пароля (dev-сессия в подписанной cookie). Оба слоя рассчитаны на замену на Supabase.

## Сценарии

**Преподаватель** (`/teach`): создать курс или добавить готовый демо-курс → загрузить PDF/TXT/MD или вставить текст → «Собрать уроки» (с проходом методиста-ревьюера) → поправить в редакторе, переставить, опубликовать → дать студентам код или ссылку `/join/КОД`. Вкладки: Материалы, Уроки, Генерация (задание, тест, конспект, план занятия, структура презентации), Чат по материалам, Проверка ДЗ (вставка текста или CSV из LMS, выгрузка результатов в CSV), Студенты, Настройки (образовательные результаты, тон, лимит уроков в день, образцы оценок для калибровки, расход по операциям).

**Студент** (`/learn`): ввести код курса → урок дня (интро → задача → фидбек по критериям) → возражение на оценку, если не согласен → повторение (`/learn/review`, 2–3 карточки на урок) → история ответов (`/learn/history`). По умолчанию один новый урок в день. Письмо «урок дня» уходит кроном (`/api/cron/daily`, Resend), если задан `RESEND_API_KEY`.

## Структура

- `src/app/` — страницы (App Router) и route handlers в `src/app/api/`
- `src/lib/ai/index.ts` — единственная точка вызова модели с учётом расхода; `providers/` — Anthropic и OpenAI-совместимый; `demo.ts` — заглушки
- `src/lib/prompts/` — промпты, один файл на промпт (править можно без кода)
- `src/lib/db/` — схема и запросы SQLite
- `src/lib/lessons/types.ts` — zod-схемы урока, фидбека, результатов проверки
- `src/lib/progress/` — streak, XP, интервалы повторения
- `src/lib/auth/` — сессия и проверки доступа
- `content/courses/` — готовые курсы для кнопки «Добавить демо-курс»
- `docs/` — разбор продукта с шести позиций и страница технологии для Сколково
- `src/components/` — UI (shadcn/ui в `ui/`, остальное по ролям)
