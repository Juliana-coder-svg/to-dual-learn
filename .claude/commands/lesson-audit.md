---
description: Методический аудит уроков курса или файла курса-примера по паттернам обучения.
argument-hint: [id курса в Supabase или путь к content/courses/*.json]
---

Вызови агента `methodist` для аудита уроков: $ARGUMENTS. Если указан id курса, уроки нужно получить из Supabase скриптом с service role ключом из .env.local (ключ не печатать); если путь к файлу, читать файл. Методист должен пройти по каждому уроку с чек-листом навыка `learning-design` и выдать: вердикт по курсу, находки по урокам, готовые исправленные тексты задач и критериев там, где нужно. Правки в файл курса-примера вносить сразу; правки в базе — только после подтверждения пользователя.
