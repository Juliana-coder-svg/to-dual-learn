# To Dual Daily — Project Guide for Claude Code

This file is read at the start of every Claude Code session. It defines what we're building, how, and the rules of engagement.

## Что мы строим

**To Dual Daily** — веб-приложение для микрообучения навыкам мышления в эпоху AI.

Стартовая вертикаль — «Критическое мышление в эпоху AI»: 5–15 коротких уроков по 5 минут каждый. Пользователь проходит один урок в день, отвечает на задачу, получает фидбек от AI-ментора, накапливает streak и очки. Через 1, 3, 7 дней возвращаются флешкарты для повторения.

Стратегическая цель — воронка для бренда To Dual Education (корпоративное AI-обучение, магистратура ИИМУП × НИУ ВШЭ). Приложение бесплатное, его задача — дать максимально широкой аудитории попробовать формат и привести часть из них в платные продукты.

## Кто пользователь

- Маркетологи, продакты, аналитики, менеджеры 25–40 лет
- В РФ (но без жёсткой геоблокировки)
- Хотят прокачать прикладные навыки мышления
- Терпимы к AI, но устали от рекламных AI-курсов

## Стек

- **Фронтенд:** Next.js 15 (App Router), TypeScript strict, Tailwind CSS, shadcn/ui
- **Бэкенд:** Next.js API routes (server actions) + Supabase
- **БД и Auth:** Supabase (Postgres, Auth, Row Level Security)
- **AI:** Anthropic Claude API через server-side route (ключ только на бэкенде)
- **Деплой:** Vercel
- **Аналитика:** Yandex Metrika + PostHog

## Архитектурные правила

1. **TypeScript strict mode**, никаких `any` без явного обоснования в комментарии
2. **Server Components по умолчанию**, `"use client"` только когда реально нужно (интерактивность, state, эффекты)
3. **AI-ключи только на сервере.** Никогда не передавать `ANTHROPIC_API_KEY` в клиент. Все запросы к Claude — через `/app/api/...` или server actions.
4. **Контент уроков — в файлах**, не в БД. Папка `/content/lessons/*.json`. Это позволит редактировать уроки через git, без админки на первых этапах.
5. **Промпты — в отдельной папке** `/lib/prompts/`. Один промпт = один файл, чтобы методист (Лера) могла редактировать без знания кода.
6. **Сохранять прогресс в Supabase**, но иметь fallback на localStorage для незарегистрированных пользователей.
7. **Никаких сторонних UI-китов**, кроме shadcn/ui. Никакого Material UI, Ant Design и т.п.
8. **Никаких градиентов и теней в дизайне.** Плоский минимализм. Цвета — из Tailwind с осмысленным семантическим назначением.

## Правила работы со мной (Claude Code)

1. **Plan Mode для крупных задач.** Если задача больше, чем «поправь один файл», — сначала покажи план, потом делай.
2. **Атомарные коммиты.** Один коммит = одно изменение. Сообщения коммитов на английском, императив: `add lesson page`, `fix streak counter bug`.
3. **Не трогай чужой код без необходимости.** Если задача про урок — не правь авторизацию.
4. **Никогда не удаляй файлы без подтверждения.**
5. **Не добавляй зависимости без обсуждения.** Каждый новый npm-пакет — это технический долг.
6. **Если что-то непонятно — спроси.** Не угадывай.
7. **Тестируй после изменений.** Запусти dev-сервер, проверь, что не сломалось.

## Что НЕ делаем

- Не делаем нативное мобильное приложение
- Не делаем Telegram-бота (заблокирован в РФ)
- Не делаем сложную геймификацию на старте (лидерборды, друзья, чаты)
- Не делаем платную подписку до того, как продукт стабилизируется
- Не делаем админку, пока контент помещается в JSON-файлы
