# Шаблоны документов оператора

Дата: 8 октября 2026. Юрлицо продукта пока не названо, везде стоят заглушки в квадратных скобках. Когда Юлиана назовёт юрлицо, заглушки заменяются поиском по всей папке `docs/legal/`.

Все шаблоны — проекты для юриста, не заключения. Нормы указаны со ссылкой на закон и даты редакций; текст закона целиком в этой работе не читался, поэтому каждую ссылку юрист сверяет по актуальной редакции (помечено «проверить»).

## Единые заглушки

| Заглушка | Что подставить | Где используется |
|---|---|---|
| `[ЮРЛИЦО]` | полное название, например «ООО "…"» | везде |
| `[ЮРЛИЦО_КРАТКО]` | краткое название | договоры, акты |
| `[ИНН]`, `[ОГРН]`, `[КПП]` | реквизиты | везде |
| `[АДРЕС_ЮР]` | юридический адрес | везде |
| `[РУКОВОДИТЕЛЬ]` | ФИО и должность подписанта, основание полномочий | приказы, договоры |
| `[ОТВЕТСТВЕННЫЙ]` | ФИО, должность ответственного за обработку ПД (ст. 22.1 152-ФЗ) | политика, уведомление РКН, приказ |
| `[ПОЧТА_ПДН]` | почта для запросов по данным, например privacy@[домен] | политика, согласие |
| `[ДОМЕН]` | адрес сервиса | везде |
| `[ЦОД]` | поставщик и город размещения (после переезда: Selectel, [город]) | политика, уведомление РКН, договоры |
