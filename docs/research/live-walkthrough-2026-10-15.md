## 5. Заголовок лендинга

Вопрос владельца: «им нравится? им всё понятно?». Короткий ответ: текущий заголовок понятен на 3 из 5 и нравится на 2 из 5 у всех троих. Он длиннее девяти слов (десять), «по … по» подряд, глагол «практикуются» не говорит, чем именно, и ни слова о пользе для преподавателя. На телефоне занимает шесть строк.

Варианты составлены по textskill (конкретный результат, кто и что получит, до девяти слов, без прилагательных без факта). Каждый проверен на факты: «итог остаётся за вами» совпадает с рекомендательным баллом, «каждый ответ» с разбором по критериям. Сканер `npm run text:lint` на всех вариантах: 0 жёстких, 0 предупреждений.
