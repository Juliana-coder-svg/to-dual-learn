## Проверки

- Lighthouse на `/` (production-сборка, локально): мобильный Performance 91, Accessibility 100, Best Practices 100, SEO 100 (LCP 3,5 с при троттлинге, CLS 0); десктоп 100 / 100 / 100 / 100.
- Горизонтальной прокрутки нет: `scrollWidth` 375 при 375 и 1280 при 1280.
- `npm run type-check`, `npm run lint`: без ошибок. `npm run text:lint`: жёстких нарушений 0.
- Marketer предложил поднять «Что видит преподаватель» на второе место и убрать плитку студента. Не принято: порядок, четыре роли и три шага заданы владельцем.
- Editor предложил «To Dual Education» вместо «TO DUAL Education». Не принято: так пишется бренд в продукте.
- Code-reviewer: у одинаковых кнопок «Собрать курс» добавлен `aria-label` с ролью. Замечание про контраст на оранжевой плашке снято: графит на оранжевом даёт 6,5:1 (docs/design.md), Lighthouse подтвердил.

## Ограничения

- Шаг 2 показывает вкладку «Уроки» с пометкой «Черновик ИИ» и кнопками правки, а не экран с предложениями ИИ: ключ модели в сборке для съёмки не сработал (401), а тратить время на отладку не стали. Снимок можно заменить, подпись остаётся верной.
- В трёх колонках шагов снимки сжаты до ~315 px, мелкий текст на них не читается на 1280, на 375 читается. Для лучшей читаемости шаги можно перевести в ряды по одному.
- Снимки показывают вымышленных студентов и адреса `land-*@example.test`.
