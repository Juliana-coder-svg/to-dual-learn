# Вкладка «Студенты» отвечает на вопрос «кто где» (16 октября 2026)

Основание: восемь респондентов (docs/research/live-walkthrough-2026-10-16.md, разделы 2, 5, 6, 8), правка 3 из топ-5. Лендинг обещал «видно, кто проходит», а экран показывал только пройдено, средний балл, дни подряд и баллы.

## Что сделано
- Состояние каждого студента: **не начал** (записан, ответов нет), **застрял**, **сдал**, плюс нейтральное **идёт** для остальных, чтобы таблица не оставляла никого без статуса. Рядом дата последнего ответа и число пройденных уроков.
- Сводка-фильтр над таблицей: «Все · Не начали N · Застряли M · Сдали K · Идут». Ссылки `?state=…`, значение проверяется по белому списку.
- Одна строка пояснения: что такое баллы, серия (дни подряд) и когда студент считается застрявшим.
- Выгрузка CSV (имя, почта, состояние, пройдено, последний ответ, средний балл): разделитель «;», BOM, кнопка выгружает то, что показано с учётом фильтра.
- Лендинг (карточка «L&D в компании»): подпись теперь описывает именно этот экран и выгрузку.

## Определения (src/lib/learning/student-state.ts, тесты scripts/student-state.test.ts)
- Берутся только опубликованные уроки. «Пройден» — есть хотя бы один ответ.
- **Сдал**: есть ответ на последний опубликованный урок. Приоритет: сдал, застрял, идёт.
- **Застрял**: не сдал и либо последняя попытка на каком-то уроке оценена в 1–2, либо с последнего ответа прошло больше 3 суток.
- **Не начал**: ответов нет вовсе. Студент без единого ответа не становится «застрявшим» даже через месяц: в задаче это состояние называется «не начал».
- Схема, RLS и RPC не менялись, миграции нет. Сдачи берутся из `listLessonAnswersForSignals` (под сессией преподавателя, RLS).

## Решения ревью
Исправлено: формулы в CSV (ведущий апостроф для ячеек с `= + - @`, это касается и выгрузки проверки работ); ошибка запроса сдач больше не прячется под пустой список; тип `searchParams`; выгрузка по фильтру.
Оставлено осознанно, решать методисту и продакту:
1. Низкий балл по раннему уроку держит «застрял», пока студент не пересдаст этот урок.
2. «Сдал» значит «ответил на последний урок», а не «прошёл все». Если опубликовать новый урок, «сдавшие» станут «идут».
3. «Средний балл» из RPC считается и по черновикам, «Пройдено» — только по опубликованным.
4. Запрос сдач тянет `select *` по всем ответам курса; на больших группах нужен узкий запрос или RPC (миграция 0007).
