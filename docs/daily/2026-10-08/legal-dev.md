Исправлено по его находкам (коммит `harden consent gate…`): открытый редирект через `next=/\evil.com` (общая проверка пути `src/lib/auth/next-path.ts` во всех четырёх местах; дыра была и до этой ветки); согласие теперь проверяется и в `teacherCourse`/`studentCourse` (значит, и во всех API-маршрутах с моделью) и на `/join/КОД`, а не только в `AppShell`; удаление блокируется и когда у бывших студентов остались ответы на уроках курса; выгрузка больше 4 МБ после урезания материалов отдаёт 413 с текстом; в `docs/deploy.md` записан порядок «сначала миграции, потом деплой». ## Что не проверено и почему

Миграции `0002`–`0004` на проекте Supabase не применены: запуск SQL в панели проекта классификатор разрешений расценил как изменение общего ресурса и заблокировал. SQL лежит в `supabase/migrations/`, применять по порядку в SQL Editor. Пока таблицы нет, любая страница с сессией падает на проверке согласия (`consent check: Could not find the table 'public.consents'`), это ожидаемо. После миграций нужно пройти в браузере на 3004: вход с согласием (три строки в `consents`), повторный вход без рассылки (строк не прибавляется), `/account/data`, выгрузка JSON, удаление тестового пользователя `name@example.com`, блокировка удаления у преподавателя со студентом, правка урока → «Проверен», проверка методистом → «Не проверен», гейт `/consent` после удаления строки `processing`.

## Что отложено

- Отметка «Мне 18 лет или больше» на входе (`consent.md`, задача 5): ждёт решения юриста, нужна ли она без школьного режима. Если да: ещё один обязательный чекбокс и `kind = 'age18'`, полчаса.
- Передача курса другому преподавателю: без неё преподаватель со студентами не может удалить аккаунт. Отдельная задача на 0,5–1 день.
- Редирект из `AppShell` на `/consent` не передаёт текущий путь: после согласия человек попадает на главную своей роли, а не на урок из письма. Server Component не знает свой путь без заголовка из proxy; proxy.ts правит другая сессия.
- Хранение обезличенного подтверждения согласия после удаления аккаунта: сейчас строки `consents` уходят каскадом. Вопрос юристу.
- Подпись «создано ИИ» в CSV проверки работ не добавлена: лишняя строка ломает импорт таблицы.
- Роль «преподаватель» по-прежнему выбирает сам пользователь. Прав она не даёт, подтверждаемая роль нужна только для школьного режима.
