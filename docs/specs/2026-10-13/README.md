## Что из запроса уже сделано

- Лендинг про платформу уже есть: главная `/`, четыре блока. Не хватает пути без кода, второго контура, вопросов и ответов.
- `/join/КОД` уже даёт ссылку на курс. «Тренажёр по ссылке» не новый механизм, а упаковка: кнопка, текст приглашения, экран входа с названием курса.
- `/account/data` уже половина кабинета (данные, согласия, удаление).
- Концепт «курс учится у студентов» к этим четырём запросам не относится, он работает после ответов группы.
