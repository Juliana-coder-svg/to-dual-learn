# Дизайн To Dual Learn: словарь элементов

Токены живут в `src/app/globals.css`, общие компоненты в `src/components/shared`. Этот файл объясняет, что чем является и когда что применять. Правила CLAUDE.md остаются: плоский минимализм, без градиентов и теней, один акцент, только shadcn/ui.

## Принципы

- **Один акцент.** Фирменный оранжевый `#FF4A07` (`--primary`). Для мелкого текста на белом используется `--primary-strong` (темнее, контраст выше 4,5:1); сам `--primary` для текста годится только крупному (от 24 px полужирного).
- **Оранжевый это поверхность, а не только кнопка.** На экране может быть один сплошной оранжевый блок: «Урок дня», финальный призыв на лендинге, финал повторения. Внутри него кнопки белые (`variant="inverse"`), подписи белые с прозрачностью.
- **Цифры как на счётчике.** Номер урока, серия дней, баллы, оценка показаны крупно табличными цифрами. Это фирменный приём: число читается раньше подписи.
- **Сегменты шага как знак.** Три сегмента (идея, задача, разбор) повторяются в уроке, в плашке «Урок дня», в карточках курсов (по сегменту на урок) и в повторении (по сегменту на карточку).
- **Меньше коробок.** Карточка с рамкой только у того, на что можно нажать (курс в списке) или что нужно отделить от потока (урок в списке преподавателя). Формы и справочные блоки живут секциями: заголовок, подпись, разделитель `border-t` или подложка `bg-surface`.
- **Воздух вместо линий.** Между секциями лендинга `py-20`/`py-24`, между блоками рабочих экранов `mt-10`/`mt-14`. Мера текста не шире `max-w-prose`.
- **Движение короткое и по делу.** Смена шага урока и появление разбора: подъём на 8 px с проявлением за 300 мс (`.step-enter`). Полоса прогресса вырастает слева направо за 600 мс (`.bar-grow`). При `prefers-reduced-motion` анимации выключены.

## Шрифт

Onest с кириллицей, подключён через `next/font/google` в `src/app/layout.tsx` (переменная `--font-onest`), системный стек остаётся запасным. Решение владельца от 8 октября 2026; раньше был системный шрифт. Заголовки с отрицательным трекингом: display −0,03 em, title −0,025 em, counter −0,04 em. В Onest это не слишком плотно, проверено на /learn и в уроке.

## Шкала текста (утилиты)

| Утилита | Размер | Где |
| --- | --- | --- |
| `type-display` | 44 → 72 px (clamp по ширине окна) | заголовок лендинга, `PageHeader size="lg"` |
| `type-title` | 28 → 40 px | заголовки страниц, название урока, заголовок в плашке «Урок дня» |
| `type-heading` | 20 px | заголовки секций и карточек |
| `type-counter` | 40 → 56 px, табличные цифры | номер урока, серия, баллы, оценка, код курса |
| `type-body` | 15 px / 1,6 | основной текст уроков и описаний |
| `type-caption` | 12 px | подписи, пометки, `eyebrow` |

Размеры текучие, поэтому `md:`-префиксы к ним не нужны.

## Цвета (токены)

| Токен | Назначение |
| --- | --- |
| `primary` | фирменный оранжевый: кнопки, плашки, закрашенные сегменты, крупные цифры |
| `primary-strong` | тёмно-оранжевый для мелкого текста и hover кнопок |
| `primary-soft` | светлая подложка `.callout` («Идея урока», «Запомнить», «Один следующий шаг») |
| `surface` | подложка служебных секций (письмо с уроком дня, готовые курсы, приглашение) |
| `muted` | серые незакрашенные сегменты, фон цитат с данными |
| `border` | рамки карточек и разделители |

## Компоненты и классы

**`.accent-panel`** — сплошной оранжевый блок, скругление 8 px, отступы 24/32 px, белый текст. Внутри: `.eyebrow` становится белым с прозрачностью, подписи `accent-panel-muted`, кнопки `variant="inverse"` (белая) и `inverse-outline` (белая рамка). Один на экран.

**`StepMarks`** (`src/components/shared/StepMarks.tsx`) — ряд сегментов. `total`, `filled` (закрашено слева), `current` (текущий, полупрозрачный), `labels` (подписи под сегментами), `size` sm 6×20 px / md 8×48 px / lg 10 px во всю ширину, `tone="inverse"` для оранжевой плашки. С `label` становится `progressbar` для screen reader, без него декоративный. Больше 24 сегментов рисуются сплошной полосой.

**`.card-link`** — карточка-ссылка: на наведении рамка оранжевая, заголовок `group-hover:text-primary-strong`. Без тени и сдвига.

**`.callout`** — светлая подложка с подписью `.callout-label`. Для мыслей, которые надо выделить, но не кричать.

**`.eyebrow`** — надпись капителью над заголовком: «Урок 3 · шаг 2 из 3», «Опубликовано».

**`.empty-state`** — пунктирная рамка, текст по центру, действие внутри.

**`.data-table`** — таблица с табличными цифрами и приглушённой шапкой.

**`PageHeader`** — ссылка назад, eyebrow, заголовок (`type-title`, или `type-display` при `size="lg"`), описание до `max-w-prose`, действия справа; на телефоне действия переносятся, не вылезая за экран.

**`SectionHeader`** — заголовок секции внутри страницы: используется там, где раньше были карточки (настройки курса, материалы, уроки).

**`Button`** — размеры default 36, sm 32, lg 44 px. Варианты: default, outline, ghost, secondary, destructive, link, inverse, inverse-outline.

**`Badge`** — круглая плашка 22 px: default (акцент), secondary (серая), soft (светло-оранжевая), outline.

**`AiNote`** — пометка «ИИ» одной строкой, форма одна на все экраны.

## Экраны: что где

- **Лендинг.** Заголовок `type-display`, шаги с номерами `type-counter` оранжевым, сегменты «Для кого», исследования на `bg-surface`, финальный призыв в `.accent-panel`.
- **/learn.** Три счётчика (`type-counter` над подчёркиванием), плашка «Урок дня» для первого курса с непройденным уроком, карточки курсов со `StepMarks` по урокам, боковая колонка секциями.
- **Курс студента.** Прогресс `StepMarks size="lg"`, плашка «Урок дня» с номером, список уроков с номерами `01…` и разделителями.
- **Урок.** `StepMarks` с подписями в шапке, номер урока `type-counter`, шаги появляются через `.step-enter`, в разборе оценка, баллы и серия крупными цифрами.
- **Повторение.** Сегменты по карточкам, карточка и ответ через `.step-enter`, финал в `.accent-panel`.
- **/teach.** Карточки курсов `.card-link` со `StepMarks` (опубликовано/всего) и крупными цифрами; «Новый курс» и «Готовые курсы» секциями.
- **Настройки курса.** Четыре секции с разделителями, код курса `type-counter` моноширинным.
- **Уроки преподавателя.** Номер `type-counter`, действия на отдельной строке до `xl` (1280 px).

## Чего не делаем

Градиенты, тени, второй акцентный цвет, иконочные шрифты, сторонние UI-киты, анимации дольше 600 мс.
